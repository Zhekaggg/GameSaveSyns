# Game Save Sync (GSS)

**Синхронизация сохранений PC-игр между компьютерами через облако. Без флешек и ручного копирования папок.**

Играешь на ПК и на ноутбуке? Game Save Sync сама скачивает свежее сохранение перед запуском игры, запускает игру, а после выхода отправляет сохранение в облако. Работает с любой облачной папкой: OneDrive, Google Drive, Яндекс Диск, Dropbox.

Проект сделан для **Savage Wind** (неофициальный нативный порт *The Legend of Zelda: Breath of the Wild* для ПК), но подходит для любой игры, у которой есть папка с сохранениями.

> Программа копирует **только папку сохранений**, которую ты укажешь, а не саму игру. Файлов игры в репозитории нет. Проект не связан с Nintendo и авторами Savage Wind.

## Возможности

- **Автоматическая синхронизация.** Перед игрой скачивается свежее сохранение, после выхода из игры отправляется в облако.
- **Запуск игры через ярлык.** Ярлык на рабочем столе с иконкой игры и названием вида `Название игры (gss)`: нажал и играй.
- **Сравнение по содержимому, а не по времени.** Часы двух компьютеров могут расходиться, поэтому программа сравнивает сами файлы и помнит, что было синхронизировано в прошлый раз.
- **Защита от потери прогресса.** Если сохранение менялось и на ПК, и в облаке, программа не перезаписывает молча, а спрашивает, какое оставить. Второе остаётся в резервной копии.
- **Ожидание облака.** Если клиент облака ещё докачивает файлы с другого компьютера, программа ждёт и не принимает недокачанное.
- **Резервные копии.** Максимум 3 копии, имя папки содержит дату последнего сохранения (`2026-11-11__19-03`), внутри файл `info.txt`. Копия не создаётся, если файлы не изменились. Новая копия заменяет самую старую. Папку для копий можно выбрать.
- **Окно прогресса.** Сразу после закрытия игры появляется окно с индикатором отправки в облако.
- **Слежение за процессом игры.** Программа определяет, когда игра действительно закрылась (и не перезапустилась), и только после этого отправляет сохранение. Подходит и для игр, которые запускаются через лаунчер.
- **Иконка игры.** Иконка копируется с ярлыка игры (`.lnk`, `.url`), из `.exe` или из картинки и ставится на окна приложения и на ярлык.
- **Служебные файлы облака игнорируются** (`.tmp.drivedownload`, `desktop.ini`, `Thumbs.db` и т. п.).
- **Интерфейс на русском и английском.** Вставка и копирование работают с `Ctrl` на любой раскладке.

## Требования

- Windows 10 / 11
- Python 3.9+ (только для запуска из исходников; `tkinter` входит в стандартную установку)
- Клиент облака на обоих компьютерах (OneDrive, Google Drive, Яндекс Диск, Dropbox и т. п.), вход в один и тот же аккаунт

Сторонние библиотеки не нужны.

## Быстрый старт

1. Скачай `save_claude_1.py` (или собранный `.exe`) на оба компьютера.
2. Создай в облаке отдельную папку для сохранений, например `OneDrive\GameSaves\SavageWind`. В облачном клиенте включи для неё «Всегда хранить на этом устройстве» (для OneDrive / Google Drive).
3. Запусти программу. Откроется окно настроек (**SETUP**). Укажи:
   1. **Папку сохранений** игры. Для Savage Wind это папка `save` рядом с `savagewind.exe`.
   2. **Папку в облаке**.
   3. **Файл игры** (`savagewind.exe`).
   4. *(необязательно)* **Папку для резервных копий**.
   5. *(необязательно)* **Ярлык игры или картинку** для иконки. Если оставить пустым, иконка берётся из `.exe` игры.
4. Нажми **«СОЗДАТЬ ЯРЛЫК НА РАБОЧЕМ СТОЛЕ»** и дальше запускай игру через этот ярлык.
5. Повтори на втором компьютере. Пути на компьютерах могут отличаться.

Запуск самой программы без аргументов всегда открывает настройки. Синхронизацию и игру запускает ярлык.

## Как это работает

```
Ярлык "Игра (gss)"
   │
   ├─ 1. Проверка облака (при необходимости ждёт докачки)
   │     ├─ в облаке новее, на ПК не менялось → скачивает
   │     ├─ менялось и тут, и там           → спрашивает, какое оставить
   │     └─ всё совпадает                   → ничего не делает
   ├─ 2. Запуск игры и слежение за её процессом
   ├─ 3. Игра закрыта (проверка, что она не перезапустилась)
   ├─ 4. Резервная копия (если файлы изменились)
   └─ 5. Отправка в облако, окно с прогрессом
```

Рядом с программой создаются служебные файлы:

| Файл | Назначение |
|---|---|
| `config.json` | настройки |
| `sync_state.json` | что считалось синхронизированным в прошлый раз (не удаляй) |
| `sync_log.txt` | журнал шагов с точным временем, удобен для поиска проблем |
| `backups/` | резервные копии (если не выбрана другая папка) |
| `app_icon.ico`, `app_icon.png` | иконка, скопированная с ярлыка игры |

В облачной папке появляется скрытый файл `.gss_state.json` с отметкой, с какого устройства и когда отправлено сохранение.

## Командная строка

```
save_claude_1.py            открыть настройки (SETUP)
save_claude_1.py run        синхронизация → игра → отправка (так работает ярлык)
save_claude_1.py pull       только забрать сохранение из облака
save_claude_1.py push       только отправить сохранение в облако
```

## Дополнительные настройки `config.json`

| Ключ | Описание |
|---|---|
| `process_name` | имя процесса игры (например `eldenring.exe`), нужно для игр, запускаемых через лаунчер |
| `game_name` | название для ярлыка `Название (gss)`, если нужно другое |
| `close_grace_seconds` | сколько секунд после закрытия игры проверять, что она не перезапустилась (по умолчанию 5) |
| `icon_source` | путь к ярлыку, `.exe` или картинке для иконки |
| `language` | язык интерфейса: `ru` или `en` |

## Сборка в `.exe`

```
pip install pyinstaller
pyinstaller --noconsole --onedir --name GameSaveSync save_claude_1.py
```

Рекомендуется режим `--onedir`: так не создаётся временная папка при каждом запуске, и не бывает предупреждения `Failed to remove temporary directory`.

## Ограничения

- Только Windows. На телефонах не работает.
- Синхронизируется одна игра (один набор путей в `config.json`).
- Нужен клиент облака с локальной папкой. Прямой работы с API облаков нет.
- Если в одной облачной папке одновременно играют на двух компьютерах, сработает защита от конфликтов, но лучше этого не делать.
